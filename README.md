# Swarag-Gyani

Emergency numbers for India. A plain website: no server, no API key, no installs.

## Run it
Double-click `index.html`. That is all.

Files: `index.html`, `style.css`, `script.js`.

## Put it online
Upload the three files to any static host (GitHub Pages, Netlify, Cloudflare Pages).

## Update numbers
Edit the `S` (state-wise) and `NAT` (national) lists at the top of `script.js`.
Always check numbers against official government sources before publishing.
